# 🕌 Islami App

An Islamic mobile application built using Flutter that provides Qur’an images, Hadith collection, and a digital Tasbeeh feature for daily remembrance.

---

## ✨ Features

- 📖 Qur’an images browsing
- 📜 Hadith collection
- 🔍 Search functionality to find content easily
- 📿 Digital Tasbeeh counter
- 🎨 Simple and clean UI design
- 📁 Well-structured project architecture

---

## 🛠️ Tech Stack

- Flutter
- Dart
- Git & GitHub

---

## 📱 App Highlights

- Lightweight and easy to use
- Organized code structure
- Beginner-friendly implementation with clean separation of files
